# Star Simulator

Explore six animated star compositions in a Three.js/WebGL experiment by Taylor Allen / Syntax. Taylor-owned code is available under the [MIT License](LICENSE), with [separate dependency and shader notices](THIRD_PARTY_NOTICES.md).

[Live experience](https://labs.sntx.co/experiments/twigl-plume-sphere/) · [Run and edit this project](LABS.md)

```sh
npm test
npm start
```

Node.js 20+; no installation needed to preview the checked-in Labs runtime. The editable authoring snapshot may predate Labs changes; see LABS.md before rebuilding it. The website is deployed separately and may run an earlier source revision.
